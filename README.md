# Chromora

Eight colours. Two quiet choices. A reading of now.

A local-only progressive web app inspired by Max Lüscher's 1947 colour-preference idea. Not the official Lüscher Color Test. Not a diagnosis. Not therapy.

- Two ranking rounds with a short eye-rest between them
- Original interpretive copy (no copyrighted scoring tables)
- History stays on the phone
- Add to Home Screen

Open `index.html` or deploy the folder. Nothing leaves the device.
